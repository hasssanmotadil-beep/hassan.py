# Mes Projets Python - Formation BTS

Ce dépôt (repository) contient mes premiers pas en programmation Python. J'y ai développé plusieurs scripts pour mettre en pratique les bases de l'algorithmique.

## 1. Calculatrice Interactive (`calc.py`)
Un programme qui permet d'effectuer les opérations arithmétiques de base.
- **Concepts utilisés** : Boucles `while`, conditions `if/elif/else`, et gestion des fonctions.
- **Gestion d'erreurs** : Le programme gère les divisions par zéro et les entrées non numériques.

## 2. Gestionnaire de Moyenne (`moyenne_bts.py`)
Un script pour calculer la moyenne générale à partir d'une liste de notes.
- **Concepts utilisés** : Listes (`append`), calculs mathématiques, et boucles.
- **Logique** : Le programme affiche si l'étudiant est "Admis" ou "Ajourné" selon la moyenne obtenue.

## Outils Utilisés
- **Langage** : Python 3
- **IDE** : Visual Studio Code
- **Version Control** : Git & GitHub Desktop
